# dart_pubdev_mcp example

A minimal demonstration of `dart_pubdev_mcp` searching for packages via the MCP protocol.

## Running the example

```bash
# Activate dart_pubdev_mcp globally
dart pub global activate -s path ..

# Start dart-pubdev-explorer and query it via an MCP client
dart-pubdev-explorer
```

See the parent [README](../README.md) for full MCP client configuration.
